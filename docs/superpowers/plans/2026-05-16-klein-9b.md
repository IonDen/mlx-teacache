# v0.3.0 Klein 9B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `flux2-klein-9b` support to mlx-teacache with freshly calibrated polynomial coefficients, drop the deprecated `Img2ImgNotSupportedError`, and lay the variant-flag groundwork in the calibration script that v0.4 / v0.5 will reuse.

**Architecture:** Six-touch change. `detect.py` and `api.py` learn about the new variant id; `coefficients.py` grows one registry entry; `scripts/calibrate_flux2_klein.py` is renamed `scripts/calibrate_flux2.py` and parameterized via `--variant`; tests parametrize over the supported list; README + CHANGELOG + `docs/calibration.md` get a row each. The runtime hot path (lifecycle, gate, forward, cache) is already variant-agnostic and not touched.

**Tech Stack:** Python 3.11+, `mflux>=0.17,<0.18`, MLX, `numpy.polyfit`, pytest, ruff.
